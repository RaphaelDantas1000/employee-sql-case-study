# Employee SQL Case Study

## Project Overview

This project uses a sample employee database to answer business questions involving salaries, departments, locations, management relationships, commissions, and job titles.

MySQL was used to retrieve, combine, aggregate, and interpret relational employee data.

## Business Questions

The SQL queries examine:

- Highest-paid employees
- Employee headcount by department, including departments without employees
- Average salary by department
- Employees located in Boston
- Commission totals by department
- Employees earning above the overall average salary
- Employee and manager relationships
- The city generating the highest payroll
- Employee distribution by job title

## Tools Used

- MySQL

- SQL
- Git and GitHub

## SQL Skills Demonstrated

- `INNER JOIN` and `LEFT JOIN`
- Self-joins
- `GROUP BY` and aggregation
- `COUNT()`, `SUM()`, and `AVG()`
- Subqueries
- `COALESCE()` for missing values
- Percentage calculations
- Sorting and filtering
- Business-focused interpretation
